# AutoAuth

Java package to compile JWT or OAuth2.0 at compile time

## Overview

AutoAuth is a Java library that enables you to generate and compile JWT (JSON Web Tokens) and OAuth2.0 authentication at compile time, improving performance and security.

## Features

- 🔐 JWT compilation at compile time
- 🔑 OAuth2.0 support
- ⚡ Zero runtime overhead
- 📦 Easy integration

## Installation

```xml
<dependency>
    <groupId>com.autoauth</groupId>
    <artifactId>autoauth</artifactId>
    <version>1.0.0</version>
</dependency>
```
